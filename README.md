# Voxalfa

[![Build/test](https://github.com/voxalfa/voxalfa/actions/workflows/ci.yml/badge.svg)](https://github.com/voxalfa/voxalfa/actions/workflows/ci.yml)
[![GitHub Repo stars](https://img.shields.io/github/stars/voxalfa/voxalfa?style=flat)](https://github.com/voxalfa/voxalfa/stargazers)

Voxalfa is a declarative, data-oriented language for composing and storing Tonic Sol-fa scores in a compact, human-readable format.

> [!NOTE]
> This project is in its early stages of development. More comprehensive documentation will be available soon.

## Key Features

- **Human-Readable & Ergonomic:** Clear, uniform syntax with no whitespace-based rules.
- **Easy to write:** Faimiliar and intuitive syntax for writing lines of notes.
- **Data-Oriented:** Fully typed data structure ensuring consistency across documents.
- **Multiple Output Targets:** Compile seamlessly to SVG, MIDI, and more.
- **Granular Musical Control:** Full support for dynamics, tempo modifiers, repeat markers, and volta endings.
- **Rich Lyrics Support:** Structured lyric integration with automatic alignment and layout rendering.
- **Developer-First Tooling:** Built from the ground up with developer tools in mind.
- **LLM & AI Friendly:** Structured format optimized for generation and editing by AI models.

## Roadmap

Voxalfa is currently in early development. Features are rapidly evolving, and frequent breaking changes are expected until the stable release.
