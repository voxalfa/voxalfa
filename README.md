Voxalfa is a declarative, data-oriented language for composing and storing Tonic Sol-fa scores in a compact, human-readable format.

> [!NOTE]
> This project is in its early stages of development, and breaking changes are expected. See the [documentation](https://voxalfa.github.io/documentation) for the latest guide and reference.

## Key Features

- **Human-Readable & Ergonomic:** Clear, uniform syntax with no whitespace-based rules.
- **Easy to Write:** Familiar and intuitive syntax for writing lines of notes.
- **Data-Oriented:** Fully typed data structure ensuring consistency across documents.
- **Multiple Output Targets:** Compile seamlessly to SVG, MIDI, and more.
- **Granular Control:** Full support for dynamics, multiple endings, and all kinds of directives.
- **Rich Lyrics Support:** Simple lyrics templating and alignment system.
- **Developer-First Tooling:** Built from the ground up with developer tools in mind, including a language server and a formatter.

## Getting Started

Prebuilt binaries for the CLI and the language server are available on the [releases page](https://github.com/voxalfa/voxalfa/releases) for Linux, macOS, and Windows.

For an introduction to the language and how to use the CLI, head over to the [documentation](https://voxalfa.github.io/documentation).
